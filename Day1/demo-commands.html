What is an LLM?

  • LLM means Large Language Model.
  • It produces text by predicting likely next tokens.
  • It returns generated text, not guaranteed truth.
  • Tokens are small pieces of text used for input, output, limits, and billing.
  • The context window is the amount of information the model can use in one request.

What are we doing?

  • Verify the Day 0 environment.
  • Inspect a request before sending it.
  • Run a repeatable model call.
  • Read text, model, token usage, and approximate cost.
  • Compare a vague prompt with a specific prompt.
  • Add a careful system instruction.
  • Record results and limits in prompt notes.
