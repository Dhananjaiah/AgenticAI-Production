AGENTIC AI · PRODUCTION08 / KNOWLEDGE CHECK

Can you explain the setup boundary?

Pause, answer aloud, then reveal each answer.

1. Why use a virtual environment?

It isolates this project’s interpreter context and packages, making setup more reproducible and reducing conflicts with other projects.

2. Why commit .env.example but never .env?

The example documents required variable names with placeholders. The local .env contains real credentials and must stay untracked.

3. Does a passing setup checker prove the API key is valid?

No. This checker verifies presence and imports without making a model call. The first-call lab tests provider authentication and connectivity.

4. What crosses the network in the first call?

The request includes the prompt and provider-specific metadata. The provider returns generated content and usage information. Avoid sensitive prompt data.
