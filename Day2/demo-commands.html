What are reliable outputs?

  • Ask for a clear response shape.
  • Parse response text into data.
  • Validate fields and allowed values.
  • Retry only within a fixed limit.
  • Return an honest fallback when attempts fail.

What are we doing?

  • Check the local course environment.
  • Inspect the review output contract.
  • Classify messy reviews into JSON records.
  • Validate records with Pydantic.
  • Force known malformed records.
  • Simulate repeated bad output and prove fallback.
  • Record evidence and production limits.

6. Prove malformed data is rejected without a model call

DETERMINISTIC VALIDATION TEST
python -c "import runpy; from pydantic import ValidationError; m=runpy.run_path(r'phase-1-foundations/day-02/labs/lab-2.2-validation-retries-fallback/solution/reliable_sorter.py'); check=m['validate_raw']; bad=[{'sentiment':'ecstatic','topic':'x','summary':'y'},{'sentiment':'positive','topic':'x'}];
for item in bad:
 try: check(item); print('UNEXPECTEDLY VALID',item)
 except ValidationError as e: print('REJECTED',item,'->',e.errors()[0]['loc'],e.errors()[0]['msg'])"

What this doesLoads the real Day 2 validator and feeds it an unsupported sentiment and a missing summary.

Why we do itThe test is repeatable and free. It proves known malformed data cannot silently enter the normal output path.

Pass: both examples print REJECTED with the failing field and reason.

7. Prove retry stops and fallback appears

LOCAL FALLBACK SIMULATION
python -c "import runpy; m=runpy.run_path(r'phase-1-foundations/day-02/labs/lab-2.2-validation-retries-fallback/solution/reliable_sorter.py'); fn=m['sort_one_review']; fn.__globals__['chat']=lambda *a,**k:type('Reply',(),{'text':'not json'})(); print(fn('safe test',max_tries=3))"

What this doesReplaces the provider call in the loaded function with a fake reply that is always invalid JSON, then runs the real retry and fallback code.

Why we do itThis safely proves three failed attempts stop and produce an honest needs-review result without network access or random behavior.

Pass: attempts 1–3 fail, then the result is unclear | needs-review | Could not classify automatically.
