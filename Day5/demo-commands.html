  • Pass approved text to the next step.

6. Classify supported, unsupported, and missing inputs

LOCAL INPUT CLASSIFIER
python -c "from pathlib import Path; root=Path(r'phase-1-foundations/day-05/labs'); paths=[root/'lab-5.A-summarize-a-text-file/data/article.txt',root/'lab-5.B-extract-from-pdf/data/it-helpdesk-handbook.pdf',Path('quarterly-report.xlsx'),Path('missing-document.txt')]; allowed={'.txt','.pdf'};
for p in paths:
 status='READY' if p.exists() and p.suffix.lower() in allowed else ('UNSUPPORTED: use .txt or .pdf' if p.suffix.lower() not in allowed else 'MISSING: check the path'); print(p.name,'->',status)"

What this doesRuns four paths through a simple preflight and returns a specific action for each one.

Why we do itUnsupported and missing inputs should stop before parsing or provider use, with a message the learner can act on.

Pass: TXT and PDF are READY, XLSX is UNSUPPORTED, and the missing text file is MISSING.
SCANNED-PDF DECISION
python -c "samples={'text PDF':'Useful extracted handbook text with enough words to process safely.','scanned PDF':'   '};
